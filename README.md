# Deutschlandticket Data Analysis

## 📊 Project Overview

This project performs an exploratory data analysis of the **Deutschlandticket** using Python and data science techniques. The objective is to understand user characteristics, travel behavior, ticket usage patterns, and relationships between important numerical variables.

The analysis combines **data cleaning, preprocessing, exploratory data analysis, statistical correlation, regression analysis, and visualization** to extract meaningful insights from the dataset.

## 🎯 Objectives

* Clean and preprocess the dataset
* Explore the structure and characteristics of the data
* Analyze numerical variables and their relationships
* Identify patterns and potential outliers
* Measure relationships using **Pearson correlation**
* Perform **linear regression analysis**
* Visualize numerical relationships using regression plots
* Analyze distributions using **violin plots**
* Generate meaningful conclusions from the analysis

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation and preprocessing
* **NumPy** – Numerical computations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **SciPy** – Statistical analysis and Pearson correlation
* **Scikit-learn** – Regression and machine learning utilities
* **Jupyter Notebook** – Interactive analysis

## 🔍 Data Analysis Process

### 1. Data Cleaning

The project includes several preprocessing steps:

* Checking dataset structure
* Identifying missing values
* Removing duplicate records
* Converting variables to appropriate numerical formats
* Detecting potential outliers
* Preparing clean data for statistical analysis

### 2. Exploratory Data Analysis

Different visualizations are used to understand the dataset, including:

* Distribution plots
* Histograms
* Box plots
* Bar charts
* Scatter plots
* Violin plots

These visualizations help identify distributions, differences between groups, trends, and unusual observations.

### 3. Pearson Correlation

Pearson correlation is used to measure the **strength and direction of linear relationships between numerical variables**.

A correlation matrix is also visualized to make relationships between multiple numerical variables easier to identify.

### 4. Regression Analysis

Linear regression is used to investigate relationships between selected numerical variables.

The analysis includes:

* Regression line
* Correlation coefficient
* Statistical significance
* R² value
* Regression equation

The regression visualization helps show how the dependent variable changes in relation to the independent variable.

### 5. Violin Plots

Violin plots are used to compare the **distribution and spread of numerical variables across different groups**.

They provide more information than a simple box plot by showing the shape and density of the distribution.

## 📈 Key Visualizations

The project includes:

* Numerical correlation heatmap
* Pearson correlation analysis

* Scatter plots
* Violin plots
* Distribution visualizations
* Outlier analysis
